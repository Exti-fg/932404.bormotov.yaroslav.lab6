## О проекте

«КурсLab» — веб-приложение для конвертации USD, EUR и RUB по фиксированным курсам. Сервер принимает запросы, проверяет входные данные и возвращает результат в формате JSON. Браузер показывает форму и результат, а благодаря возможностям PWA приложение можно установить и открыть без подключения к сети после предварительной загрузки.

Курсы заданы в коде и не обновляются из внешнего источника:

| Направление | Курс |
|---|---:|
| USD → EUR | 0.92 |
| EUR → RUB | 105 |
| USD → RUB | 92 |

Для обратного направления используется обратное значение курса, а при конвертации валюты в саму себя — курс 1. Например, курс RUB → USD вычисляется как `1 / 92`.

## Используемые технологии

- **Python** — язык серверной части. Нужна версия **3.10 или новее**.
- **FastAPI** — веб-фреймворк: описывает маршруты, принимает query-параметры, проверяет запросы и формирует JSON-ответы.
- **Uvicorn** — ASGI-сервер, который запускает FastAPI и принимает HTTP-запросы.
- **HTML, CSS и JavaScript** — клиентская часть: страницы, стили и интерактивная форма конвертера. Отдельный фронтенд-фреймворк не используется.
- **PWA (Progressive Web App)** — набор веб-возможностей для установки приложения и его работы при временном отсутствии сети. В проекте используются Web App Manifest и Service Worker.

Зависимости Python перечислены в `requirements.txt`. Пакет `fastapi[standard]` включает FastAPI CLI, а Uvicorn указан отдельно.

## Подготовка и запуск

Требуется Python 3.10+. В VS Code откройте папку `lab6` (**Файл → Открыть папку...**), затем создайте терминал (**Терминал → Создать терминал**). Убедитесь, что терминал открыт в папке, где находятся `main.py` и `requirements.txt`. Если используете другой терминал, перейдите в папку `lab6` командой `cd` с путём к ней на вашем компьютере.

При первом запуске создайте виртуальное окружение, активируйте его и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скрипта активации, можно не активировать окружение и использовать `.\.venv\Scripts\python.exe` вместо `python` в командах ниже.

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

- `python -m venv .venv` создаёт отдельное окружение проекта.
- `Activate.ps1` активирует его в текущем терминале.
- `python -m pip install -r requirements.txt` устанавливает зависимости из файла. Повторная установка нужна только после удаления `.venv` или изменения зависимостей.

Запустите сервер:

```powershell
python -m uvicorn main:app --reload
```

Uvicorn запускает приложение `app` из `main.py`; `--reload` перезапускает сервер при изменении кода. Откройте <http://127.0.0.1:8000>. Терминал с сервером оставьте открытым; для остановки нажмите `Ctrl+C`.

### Если PowerShell блокирует активацию

Windows может запретить запуск `Activate.ps1`. Это ограничение PowerShell. Используйте Python из `.venv` напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

При последующих запусках из папки `lab6` достаточно выполнить команду запуска сервера. Если активация работает, сначала выполните `.\.venv\Scripts\Activate.ps1`, затем `python -m uvicorn main:app --reload`. Если заблокирована — используйте команду запуска с `.\.venv\Scripts\python.exe`. Устанавливать зависимости повторно не нужно, если `.venv` сохранена и `requirements.txt` не менялся.

### Если запуск не удался

- **`python` не найден** — установите Python 3.10+ и добавьте его в PATH.
- **`No module named ...`** — установите зависимости в `.venv` командой из инструкции выше.
- **Не найден `main` или `requirements.txt`** — проверьте, что терминал открыт в папке `lab6`.
- **Порт занят** — остановите другой запущенный сервер (`Ctrl+C`) и повторите запуск.

### Проверка

- Главная страница конвертера: <http://127.0.0.1:8000/>
- Страница «О проекте»: <http://127.0.0.1:8000/about>
- Состояние сервера и курсы: <http://127.0.0.1:8000/api/status>
- Интерактивная документация API FastAPI: <http://127.0.0.1:8000/docs>
- Пример конвертации: <http://127.0.0.1:8000/api/convert?from=USD&to=RUB&amount=100>

В примере API должен вернуть JSON с суммой, результатом и применённым курсом, например:

```json
{
  "from": "USD",
  "to": "RUB",
  "amount": 100,
  "result": 9200,
  "rate": 92
}
```

## Как работает приложение

1. Браузер загружает главную HTML-страницу и подключённые к ней CSS и JavaScript-файлы.
2. Пользователь вводит сумму, выбирает исходную и целевую валюты и отправляет форму.
3. JavaScript проверяет, что сумма положительная, и отправляет `GET`-запрос на `/api/convert` с параметрами `from`, `to` и `amount`.
4. FastAPI проверяет валюты и сумму, выбирает прямой или обратный курс и вычисляет результат. Для денежных вычислений на сервере используется `Decimal`.
5. Сервер возвращает JSON. JavaScript отображает результат на странице. Некорректные данные приводят к HTTP 400 с описанием ошибки.
6. Если запрос к серверу не удаётся из-за отсутствия сети, интерфейс пытается выполнить расчёт в браузере по тем же фиксированным курсам и сообщает пользователю, что результат рассчитан офлайн.

Это демонстрационный проект: курсы фиксированные, а конвертация не обращается к банкам или внешним сервисам.

## API

| Метод и путь | Назначение |
|---|---|
| `GET /` | Главная страница с конвертером. |
| `GET /about` | Информация о проекте. |
| `GET /api/status` | Возвращает состояние API и используемые курсы. |
| `GET /api/convert?from=USD&to=RUB&amount=100` | Конвертирует сумму. Параметры: `from`, `to`, `amount`. |
| `GET /static/...` | Отдаёт клиентские файлы: стили, JavaScript, манифест и иконки. |
| `GET /service-worker.js` | Отдаёт Service Worker с областью действия для всего сайта. |

Поддерживаются только USD, EUR и RUB. Сумма должна быть конечным положительным числом. Неизвестная валюта или некорректная сумма обрабатывается как ошибка HTTP 400.

## Установка и офлайн-режим (PWA)

Для установки откройте сайт в браузере и воспользуйтесь его командой «Установить приложение» или «Добавить на главный экран» — точное название зависит от браузера и устройства. Service Worker и установка PWA доступны на `localhost` и `127.0.0.1`, а для сайта в интернете требуется HTTPS.

При первой загрузке с работающим сервером Service Worker устанавливается и заранее кеширует страницы и файлы интерфейса. Поэтому сначала откройте приложение онлайн и дождитесь завершения загрузки. После этого страницы и ресурсы оболочки могут загружаться из кеша без сети; конвертер при недоступности API рассчитывает результат локально.

API-ответы не кешируются. Офлайн-расчёт выполняется только для валют и курсов, заданных в клиентском коде. Чтобы проверить офлайн-режим, сначала загрузите приложение онлайн, затем отключите сеть или остановите сервер и обновите страницу.
