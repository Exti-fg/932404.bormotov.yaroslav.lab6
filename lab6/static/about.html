Конвертер валют

Работу выполнил Ярослав Бормотов. Приложение преобразует USD, EUR и RUB по фиксированным курсам. Серверная часть написана на Python с использованием FastAPI.

Что реализовано

  • Страницы главная и «О проекте», а также JSON-маршрут состояния API.
  • Query-параметры from, to и amount для конвертации.
  • Проверка валют и положительной суммы с HTTP 400 для некорректных значений.
  • Манифест, устанавливаемое приложение и кеширование страниц service worker.
  • Локальный расчёт по тем же курсам, если сервер недоступен офлайн.
